AI coding 从补全代码走向 delegated engineering

Coding agents become delegated engineering

一句话 Narrative

开发者工具正在从建议下一行代码，转向接受目标、运行任务、创建 PR 并让人审查结果。

为什么值得理解

Coding 是 Agent 最早出现高频、可观察工作结果的场景，也是企业采用的先行指标。

WHAT CHANGED

本期新增观察

GitHub 开始以 repo 与 PR 粒度衡量 Agent 活动，NTT DATA 则给出组织级部署与流程结果。

为什么还不能叫 Pulse

当前 evidence 全部来自回溯重建，尚未形成两个连续、非 backfill 的 live snapshot。系统因此只展示基线，不声称 Rising 或 Cooling。

下一次如何更新

下一期会比较新增 actor、真实行动、采用结果与反向证据；只有覆盖完整且通过人工审核，才改变状态。
