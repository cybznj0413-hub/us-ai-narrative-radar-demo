AI pricing 正从 seat-only 分化为 usage、outcome 与预算控制

Hybrid pricing, not one universal answer

一句话判断

企业 AI 没有收敛到单一计价模式，而是在 seat、credits、usage、outcome 与预算控制之间形成组合。

为什么现在值得读：当 AI 从偶尔问答变成持续工作，价格、用量可见性、预算责任和交付结果必须一起设计。

CLAIM → ACTION → PROOF → GAP

为什么我们这样判断？

同一项子判断横向看：市场怎么说、真实做了什么、经营上看见了什么、还缺什么。

AI 定价会走向 Hybrid

市场观点

企业开始同时讨论价值单位、推理成本和预算责任。

已观察行动

GitHub 上线 included credits + overage；Salesforce 推 pay-per-resolution。

经营验证

OpenAI 与 GitHub 都增加了用量分析和 spend controls。

仍未证明

哪种组合能同时带来可预测收入、健康毛利与客户扩张。

03

WHAT CHANGED · 30D

过去 30 天，判断具体怎样变化？

不是一个抽象的 Pulse 标签，而是一份可以检查的变化账本。

  1. 此前判断

    市场用“seat 会不会消失”描述 AI 定价变化。

  2. 新增支持

    GitHub、OpenAI、Salesforce 连续上线 usage、credits、outcome 与 spend control 产品动作。

  3. 新增挑战

    Oracle 把 AI 嵌入现有 PMS，说明部分 AI 价值仍可能被平台价格吸收。

  4. 当前结论

    升温的是 Hybrid 实验与预算治理，而不是所有软件统一转向 outcome pricing。
